OSPF Knowledge Base

ENCOR 350-401 v1.2 Domain 3 (Infrastructure) reference for OSPFv2 & OSPFv3 LSAs, area types, and neighbor states.

OSPF LSA Types (1 to 7)

Type 1 — Router LSA

Generated by every router for each area it belongs to. Describes the router's directly connected links and costs. Flooded only within its originating area (never crosses an ABR).

Type 2 — Network LSA

Generated by the Designated Router (DR) on multi-access segments (like Ethernet). Lists all attached routers on that segment. Flooded only within the local area.

Type 3 — Summary LSA (Inter-Area)

Generated by an ABR (Area Border Router) to advertise networks from one area into another area (displayed as O IA in the routing table).

Type 4 — ASBR Summary LSA

Generated by an ABR to tell routers in other areas how to reach an ASBR (Autonomous System Boundary Router) so they can calculate the cost to external routes.

Type 5 — AS External LSA

Generated by an ASBR to advertise routes redistributed from external protocols (BGP, EIGRP, Static). Flooded across the entire OSPF domain except Stub and NSSA areas (O E1 / O E2).

Type 7 — NSSA External LSA

Generated by an ASBR inside a Not-So-Stubby Area (NSSA) because Type 5 LSAs are blocked. The NSSA ABR translates Type 7 back into a standard Type 5 LSA when flooding into Area 0 (O N1 / O N2).

OSPF Area Types & OSPFv3

Stub vs. Totally Stubby Area

Stub Area: Blocks Type 4 & Type 5 external LSAs; ABR injects an O*IA 0.0.0.0/0 default route. Totally Stubby (Cisco Proprietary): Blocks Type 3, Type 4, and Type 5 LSAs—leaving only intra-area Type 1/2 plus a single default route.

NSSA & Totally NSSA

NSSA (Not-So-Stubby Area): Blocks external Type 5 LSAs from Area 0 while allowing a local ASBR to redistribute external routes using Type 7 LSAs. Totally NSSA also blocks Type 3 inter-area summaries.

OSPFv3 (IPv6) Extra LSAs — Type 8 & Type 9

OSPFv3 runs per-link over IPv6 Link-Local (fe80::/10) and adds Type 8 (Link-LSA) for link-local addresses/prefixes and Type 9 (Intra-Area-Prefix LSA) to carry IPv6 networks.

DR & BDR Election

On broadcast/NBMA networks, routers elect a DR and BDR using highest interface priority (default 1, 0 = never elect), then highest Router ID. Election is non-preemptive.
